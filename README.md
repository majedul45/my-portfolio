# Majedul Haque — Developer Portfolio

A responsive personal portfolio website showcasing my background, technical skills, education, and selected web development projects. Visitors can explore project details, review my resume, and find ways to contact me.

## Features

- **Responsive portfolio layout** for desktop, tablet, and mobile screens.
- **Hero and About sections** introducing me and my development interests.
- **Interactive skills section** with filters for frontend, backend/database, and development tools.
- **Featured projects** with technology tags, live-demo links, GitHub repositories, and individual project detail pages.
- **Project details pages** describing technologies, challenges, and potential future improvements.
- **Resume page** for viewing developer background and qualifications.
- **Education section** highlighting educational information.
- **Contact section** with contact details, social profiles, and a form interface.
- **Reusable React components** to keep the UI organized and maintainable.
- **Custom favicon and app icons** for consistent portfolio branding.
